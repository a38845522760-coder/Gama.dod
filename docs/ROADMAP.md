# Iron Yard — Development Roadmap

## Phase 1 — Foundation
- [x] Godot project skeleton, folders, core services, and architecture notes.
- [ ] Verify import/run in editor and on target hardware.

## Phase 2 — Playable core (this package)
- [x] First-person controller and camera.
- [x] Keyboard/mouse input and touch-control adapter.
- [x] Collision/physics test arena and interaction contract.
- [x] Health/runtime player data foundation.
- [x] Match lifecycle foundation.
- [x] ENet host/client transport adapter.
- [x] Rendering profile application and diagnostics foundation.
- [x] Smoke-test script and manual QA checklist.
- [ ] Run Godot headless parser/smoke test and complete manual QA on devices.

## Phase 3 — World and rendering
Industrial maps, detailed modular environment, spawn points, map boundaries, LOD/visibility, and tested content budgets.

## Phase 4 — AI and match framework
AI navigation and game-simulation behaviors, teams, match rules, scoring, timers, and results.

## Phase 5 — Inventory and progression
Game-only inventory/equipment definitions, credits, unlocks, shop transactions, and save migrations.

## Phase 6 — Core multiplayer modes
Free For All, Team Deathmatch, Capture the Flag, Bomb Mode, lobby/scoreboard/results.

## Phase 7 — Local multiplayer
Host/client rooms, 2–4 devices, local discovery, authoritative replication, reconnect, and hotspot device tests.

## Phase 8 — Zombie mode
Implement only after receiving the designer's story and specifications.

## Phases 9–12 — UI/UX, full graphics optimization, audio/polish, QA and release
A phase is not complete merely because files exist; run and document its acceptance checks.
